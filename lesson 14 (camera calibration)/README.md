## Связь этапов

Сначала выполняется калибровка камеры. Она позволяет определить внутренние параметры камеры и исправить оптические искажения изображения.

После этого выполняется ректенгуляризация: четыре угла плоского объекта сопоставляются с углами выходного прямоугольника с помощью перспективного преобразования.

Перед переходом ко второй статье камера должна стабильно публиковать:

```text
/camera/image_raw
/camera/camera_info
```

В сообщении `/camera/camera_info` должны находиться ненулевые параметры, полученные при калибровке.

---

Основная среда: ROS 2 Jazzy, Ubuntu 24.04
