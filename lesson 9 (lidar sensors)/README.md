# Урок 9. Сенсоры: 2D- и 3D-лидар

Цель урока — понять, чем робот «видит» препятствия: какие сообщения ROS 2 несут данные
лидара, какой фрейм для них обязателен и как эти данные попадают в Nav2.

Урок стоит **перед** Nav2 намеренно: костмапы, AMCL и SLAM из урока 10 работают ровно
с теми сообщениями, которые разбираются здесь.

## Контрольные проверки

1. Запустите `ros2 topic echo /scan --once` и объясните поля `angle_min`, `angle_increment`,
   `ranges`. Сколько лучей в одном скане и какой сектор они покрывают?
2. Проверьте `ros2 run tf2_ros tf2_echo base_link laser`. Что произойдёт с костмапом,
   если этой трансформации не будет?
3. Откройте скан в RViz2 (display **LaserScan**, топик `/scan`) и подберите **Fixed Frame**
   так, чтобы контур стен не «плыл» при движении робота.
4. Чем `PointCloud2` отличается от `LaserScan` по объёму данных при той же частоте?
5. Назовите задачу, где 2D-лидара принципиально недостаточно, и объясните почему.
